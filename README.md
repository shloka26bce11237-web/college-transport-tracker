College Transport Tracker

Overview

College Transport Tracker is a Python based application developed to help students access and manage basic college transportation information.

The system provides bus search, route and stop information, seat availability, seat booking, booking history, booking cancellation, bus status, and a summary report through a simple menu-driven interface.

The project is developed using basic Python programming concepts such as lists, dictionaries, functions, loops, conditional statements, string handling, input validation, and searching.

Features

Search for a bus using bus number or starting point
View bus routes and stops
Check available seats
Book a seat
View booking history
Cancel a booking
Check bus status
View transport summary report
Validate student input
Handle invalid menu choices and unavailable buses
Technologies and Tools
Programming Language: Python
Development Platform: Google Colab
Data Storage: Python lists and dictionaries

How to Run
Download or clone the project from GitHub.
Open college_transport_tracker.py in a Python environment such as Google Colab, VS Code, or another Python editor.
Run the program.
Enter the student name and student ID.
Select an option from the main menu.
Follow the instructions displayed by the program.

Project Scope

The current version is a basic Python console application. Bus routes, timings, seat capacities, and status values are stored as sample data inside the Python program.

The project does not currently use a database, GPS tracking, online booking, or real-time bus location services.
