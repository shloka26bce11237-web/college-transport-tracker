College Transport Tracker
Problem Statement

Students need convenient access to college transportation information such as bus numbers, routes, stops, timings, seat availability, and booking information. Without a structured system, finding and managing this information can be inconvenient.

The College Transport Tracker is a Python based  application designed to provide basic transportation features for students.

Scope of the Project

The project focuses on providing basic bus information and booking related functions through a simple Python console interface. It allows students to search for buses, view routes and stops, check available seats, book seats, view booking history, cancel bookings, check bus status, and view a summary report.

The current version uses sample data stored in Python lists and dictionaries and does not use a database or live GPS tracking.

Target Users

The primary target users are college students who use college transportation services.

High-Level Features

Bus search

Route and stop information

Seat availability

Seat booking

Booking history

Booking cancellation

Bus status

Summary report

Input validation and error handling
